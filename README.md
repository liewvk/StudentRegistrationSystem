# Student Registration System

A C# application for managing student registration.

## Description

This project provides a system to handle student registrations with features for managing student data and registration workflows.

## Technology Stack

- **Language**: C#
- **.NET Framework**: .NET

## Getting Started

### Prerequisites

- .NET SDK
- Visual Studio or Visual Studio Code (recommended)

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/liewvk/StudentRegistrationSystem.git
   ```

2. Navigate to the project directory
   ```bash
   cd StudentRegistrationSystem
   ```

3. Build the project
   ```bash
   dotnet build
   ```

### Usage

Run the application:
```bash
dotnet run
```

## Features

- Student registration management
- Data persistence and retrieval
- User-friendly interface
